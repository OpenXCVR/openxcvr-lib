# SFF-8636 Schemas

SFF-8636 QSFP+/QSFP28 memory pages for revisions 1.3, 1.4, 1.5, 2.0, 2.5,
2.8, 2.11, and 2.12, modelled as revision windows in this directory. The index
document revision is 2.12 (`docs/stds/sff-8636/SFF-8636-Rev2.12.pdf`). Page
titles do not name one revision. Cached documents are Rev 2.11 and Rev 2.12.
Revisions 1.3, 1.4, 1.5, 2.0, 2.5, and 2.8 (2.8 is the baseline of 2.8–2.10)
have no cached document; their windows are derived from the Rev 2.12 change
history. These schemas import shared SFF-8024 enum registries.

Entry point: [`_index.yaml`](_index.yaml).
