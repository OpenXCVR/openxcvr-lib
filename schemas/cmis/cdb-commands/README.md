# CMIS CDB Commands

One YAML file per CDB opcode or opcode/profile variant. The registry
index revision is 5.4, the same document revision as `schemas/cmis/_index.yaml`;
the set includes 5.4 opcodes. A command file's own `spec.revision` stays the
document that command's provenance cites.

Index membership is declared from [`../_index.yaml`](../_index.yaml).
