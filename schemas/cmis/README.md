# CMIS Schemas

OIF-CMIS memory pages, CDB commands, and state machines for revisions 3.0, 4.0,
5.0, 5.1, 5.2, 5.3, and 5.4, modelled as revision windows in this directory.
The index document revision is 5.4 (`docs/stds/cmis/OIF-CMIS-05.4.pdf`).
`spec.revision` on a page or command is the revision of the document that
file's provenance cites, not the only revision the file models. CMIS imports
shared SFF-8024 enum registries.

Entry point: [`_index.yaml`](_index.yaml).
